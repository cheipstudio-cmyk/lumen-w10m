# Lumen

**Gemini, Claude and ChatGPT on Windows 10 Mobile.** A native AI chat app for Lumias, built for W10M 15063 and up.

## What it does

- Bring your own key: **Google Gemini** (free key, no credit card), **Anthropic Claude**, **OpenAI ChatGPT**, or any **OpenAI-compatible** server (OpenRouter, Groq, Mistral, DeepSeek, LM Studio...)
- Keep several keys and switch service or model from the top of any chat
- Streaming answers, Markdown, free Wikipedia lookups for current facts
- Voice messages (native on Gemini, transcribed with a free Gemini key for the other services)
- Photos from the camera or gallery
- Image and file creation (Gemini or OpenAI key for images)
- Native W10M look: hamburger menu, Messaging-style bubbles, Settings-style pages, light and dark themes, accent colors
- Read aloud, share target, live tile
- 6 languages: EN, IT, ES, FR, DE, PT-BR
- Chats stay on the phone. Keys live in the Windows credential locker and go only to the service you pick

## Install

1. On the phone, turn on Settings > Update & security > For developers > **Developer mode**.
2. Download `Lumen.cer`, `Dependencies/ARM` and the `.appxbundle` from [Releases](../../releases).
3. In File Explorer, tap `Lumen.cer` to install it, then each `.appx` in `Dependencies/ARM`, then the appxbundle.

Device Portal works too: Apps > Install app, then add the dependencies.
